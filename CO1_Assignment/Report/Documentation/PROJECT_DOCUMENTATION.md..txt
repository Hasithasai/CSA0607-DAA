# CO1 Assignment – Student Registration Number Searching

## 1. Introduction
This project compares three searching algorithms for locating student registration numbers: Linear Search, Recursive Binary Search, and Hash Table Search. The objective is to study their correctness, time complexity, preprocessing cost, and performance on datasets of different sizes.

## 2. Objectives
- Implement three searching algorithms in Java.
- Test them on datasets of 1,000, 10,000, 100,000, and 1,000,000 records.
- Compare preprocessing time and lookup time.
- Analyse theoretical and measured performance.
- Recommend a suitable method for a system handling 50,000 requests per hour.

## 3. Algorithms

### 3.1 Linear Search
Linear Search examines elements one by one until the target is found or the dataset ends.

**Time complexity:** Best case O(1); average and worst case O(n).

**Space complexity:** O(1) for an iterative implementation.

### 3.2 Recursive Binary Search
Binary Search works on sorted data. It compares the target with the middle element and recursively searches the appropriate half.

**Time complexity:** O(log n) for lookup; sorting unsorted data adds O(n log n) using an efficient comparison sort.

**Space complexity:** O(log n) for the recursive call stack.

### 3.3 Hash Table Search
A hash table uses a hash function to locate a stored registration number.

**Expected lookup complexity:** O(1).

**Worst-case lookup complexity:** O(n).

**Expected construction complexity:** O(n), assuming suitable hashing and resizing behaviour.
