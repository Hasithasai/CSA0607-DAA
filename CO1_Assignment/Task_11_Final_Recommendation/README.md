# Task 11 — Final Recommendation
For exact registration-number lookup at high request volume, use a hash-based index when memory is sufficient and only exact-key lookups are required. Keep the durable database as the source of truth, enforce uniqueness there, and update the in-memory index safely when daily records arrive. If restart durability, multi-node concurrency, ordered/range queries, or memory constraints dominate, use a database-managed index (commonly a B-tree/B+ tree or hash index where supported) rather than relying on an unpersisted process-local set. Linear search is a baseline only.
