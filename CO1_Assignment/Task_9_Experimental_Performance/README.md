# Task 9 — Experimental Performance
The supplied report provides a single in-memory OpenJDK 21.0.12 run with 1,000 queries per size (500 hits and 500 misses). Values are reproduced in `Report/Documentation/supplied_single_run.csv`. The included Java benchmark can produce a fresh CSV on the machine used for submission.

Dataset sizes: 1,000; 10,000; 100,000; 1,000,000. Record preprocessing, lookup, total time, query count, operation count, and correctness. Use repeated runs (ideally 5–10 or more), warm-up, and median/percentile results for a more defensible evaluation. Do not claim the supplied single run is portable or statistically conclusive.
