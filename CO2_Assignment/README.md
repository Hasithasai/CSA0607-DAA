# CO2 Assignment – Brute-Force and Exhaustive-Search Techniques

This repository contains the seven-question implementation and report for CSA06 Design and Analysis of Algorithms, Assignment 2 (CO2).

## Contents
- `Q1_Sorting_Algorithms`: Selection, optimized Bubble and Insertion Sort
- `Q2_Sequential_Search`: successful and unsuccessful searches over changing list sizes
- `Q3_Brute_Force_String_Matching`: three text-pattern conditions and character comparison counts
- `Q4_Brute_Force_Closest_Pair`: all unique point pairs and distance calculations
- `Q5_Brute_Force_Convex_Hull`: supporting-line test and hull visualization
- `Q6_Exhaustive_Search`: exhaustive 0/1 package selection
- `Q7_Day4_Design_Challenge`: diagnosis of Q6 and dynamic-programming redesign
- `Final_Report`: formatted assignment report
- `Experimental_Data`: CSV operation-count datasets
- `Graphs`: experimental growth and comparison plots

## Run
Python 3.9+ is recommended. No third-party packages are required by the seven implementation programs.

From the repository root:
```bash
python Q1_Sorting_Algorithms/Implementation_Code/q1_sorting.py
python Q2_Sequential_Search/Implementation_Code/q2_sequential_search.py
python Q3_Brute_Force_String_Matching/Implementation_Code/q3_string_matching.py
python Q4_Brute_Force_Closest_Pair/Implementation_Code/q4_closest_pair.py
python Q5_Brute_Force_Convex_Hull/Implementation_Code/q5_convex_hull.py
python Q6_Exhaustive_Search/Implementation_Code/q6_exhaustive_search.py
python Q7_Day4_Design_Challenge/Implementation_Code/q7_redesign.py
```
